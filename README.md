# Tomer Levy — Portfolio

A modern, high-performance developer portfolio built with Next.js 16, React 19, Tailwind CSS, and Framer Motion.

## 🚀 Live Demo
- Deployed on **[Vercel](https://vercel.com)**

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion & Lucide Icons
- **Deployment:** Vercel

## 📂 Featured Projects
- **CHIP-8 Emulator:** Complete C++20 interpreter with SDL2 graphics, sound, and COSMAC VIP quirks.
- **AI-Compare Platform:** Fullstack comparative AI platform with Next.js, Node.js, and multi-model benchmark evaluation.
- **Autonomous Support Agent:** Multi-agent autonomous customer support platform with real-time analytics.
- **MineSweeper:** Desktop Minesweeper recreation with custom algorithms and classic UI.
- **Green Zebra (CloudCompEX):** Collaborative cloud-native orchid care system deployed on AWS.

## 💻 Running Locally

```bash
# Clone the repository
git clone https://github.com/TomerL44/portfolio.git

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
